# Un ejemplo cliente/servidor - Vue.js / NestJS

Este repositorio acompaña al curso **«Un ejemplo cliente/servidor - Vue.js / NestJS»**, disponible en línea en:

**➡️ [https://stahe.github.io/ales-vuejs-nestjs-sept-2026/](https://stahe.github.io/ales-vuejs-nestjs-sept-2026/)**

## Descripción general

Este curso detalla el desarrollo de una aplicación cliente/servidor completa, **RdvMedecins** (programación de citas médicas), mediante:
- un servidor **[NestJS]** que expone una API REST (autenticación JWT, base de datos MySQL, entidades TypeORM);
- un cliente **[Vue.js] 3** (Composition API, `<script setup>`, TypeScript) que consume esta API, con gestión de sesiones, internacionalización en francés/inglés (`vue-i18n`) y una interfaz adaptada al rol del usuario conectado (administrador/usuario).

Este curso retoma y amplía las funcionalidades de «lógica de negocio» de una aplicación desarrollada en versiones anteriores del curso (AngularJS 1.x, luego Angular y React), para facilitar una comparación didáctica entre estos diferentes frameworks del lado del cliente, manteniéndose el servidor NestJS coherente en todo momento.

Cada capítulo del curso ofrece comentarios línea por línea de los fragmentos de código significativos, en secciones tituladas «Comentemos este código».

## Tabla de contenido del curso

1. Introducción (arquitectura general, tecnologías utilizadas)
2. Configuración del entorno de desarrollo
3. El servidor NestJS de la aplicación RdvMedecins
4. Introducción al framework Vue.js
5. El cliente Vue.js de la aplicación RdvMedecins
6. Conclusión
